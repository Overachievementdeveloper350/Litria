## 🚀 Getting Started
Litria is a desktop app that turns your project into an interactive picture. Instead of scrolling through files and folders, you see everything on a big canvas—files become blocks, folders work like real groups on your computer, and connections show how code pieces link together. It’s perfect if you want to understand or build projects without getting lost in text.

## 🎯 What Is Litria Good For?
- **Visual Learning:** See how parts of your project connect, even if you’re new to code.  
- **Easy Organization:** Move nodes around on a canvas; folders stay as real folders on disk automatically.  
- **Building Tools:** Combine code blocks quickly, like drawing a diagram.  
- **No Surprises:** Every change you make on the canvas updates the actual files.

## 🖍️ How to Use Litria
Think of the app as a big empty space. You can:
- **Create a new project:** Choose “New” from the menu, and a blank canvas appears.
- **Add files:** Drag any file from your computer onto the canvas—it becomes a node.
- **Group files:** Put related nodes close together; they become a folder on your disk.
- **Connect pieces:** Click and draw a line from one node to another; this adds an import statement in the code automatically.
- **Save your work:** Litria keeps every change saved to your files instantly.

## 📦 Features You’ll Notice
- **Canvas-Based Projects:** No tricky profiles—just see your project as a diagram.
- **Real Folders:** Groups on the canvas are real folders on your hard drive; delete a group, and the folder goes too.
- **Automatic Imports:** When you connect two blocks, Litria writes the code link—you don’t make changes manually.
- **Keyboard & Mouse Friendly:** Move, zoom, and edit with simple clicks.
- **Built-in Power:** The app uses a solid coding engine (Monaco Editor) for editing when needed.

## 🛠️ For Advanced Users (But Clear to All)

- **Export Your Project:** Share your work as a normal file set—no special format needed.

## ❓ Troubleshooting & Tips
Q: I can’t open the app after download.  
A: Make sure you have Windows 10 or later and enough space. Try reopening the installer.

Q: The canvas is empty.  
A: Use “File > Open Folder” to load your existing project.

Q: Can I undo a connection?  
A: Right-click on the line and choose “Remove.”
